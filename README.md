# 优选生活服务平台
基于Java的企业级生活服务平台，实现用户端+管理端完整业务闭环，采用模块化架构设计，适合学习与二次开发

## 项目介绍
苍穹外卖是一套**前后端分离的生活服务平台**，覆盖全业务流程：
- 管理端：员工管理、菜品/套餐管理、订单管理、数据统计
- 用户端：微信登录、购物车、下单支付、订单查询、地址管理

采用Maven多模块架构，代码解耦、易于维护，是Java后端实战优质项目。

## 技术栈
### 后端
- 核心框架：Spring Boot、Spring MVC
- 数据持久：MyBatis、MySQL
- 工具组件：Redis、JWT、阿里云OSS
- 构建工具：Maven
- 接口文档：Knife4j(Swagger)

### 架构特点
- 模块化拆分（server+common+pojo）
- 统一异常处理、统一响应结果
- JWT身份认证
- AOP日志记录

## 模块说明
```
my-sky-take-out/
├── sky-server/      # 核心服务模块，Controller/Service业务实现
├── sky-common/      # 公共模块，工具类、常量、全局配置
├── sky-pojo/        # 数据模型，Entity/DTO/VO/枚举
└── sql/             # 数据库脚本，建表+初始化数据
```

## 快速启动
### 1. 环境准备
- JDK 8+
- MySQL 5.7+
- Maven 3.6+
- Redis（可选）

### 2. 数据库初始化
1. 创建数据库`sky_take_out`
2. 执行`sql/`目录下所有SQL脚本
3. 修改`application.yml`中数据库连接信息

### 3. 项目启动
1. IDEA打开项目，等待Maven依赖下载完成
2. 启动`SkyServerApplication`主类
3. 接口文档地址：http://localhost:8080/doc.html

## 核心功能
### 管理端
- 员工登录/退出、员工管理
- 菜品分类管理、菜品管理（含口味）
- 套餐管理、套餐菜品关联
- 订单管理、状态流转、数据统计

### 用户端
- 微信授权登录
- 地址簿管理
- 购物车操作
- 下单、支付、订单查询
